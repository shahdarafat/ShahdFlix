# ShahdFlix — Netflix Landing Page Clone

A responsive student front-end project inspired by the provided NetflixClone reference.

## Pages
- `index.html` — Home / landing page
- `login.html` — Sign in form
- `register.html` — Registration form

## Technologies
- HTML5
- CSS3
- JavaScript
- Bootstrap 5.3.3 (CDN)

## Run locally
Open `index.html` in a browser. An internet connection is needed for Bootstrap, Google Fonts, and the remote background image.

## Publish with GitHub Pages
1. Create a new public repository on GitHub, for example `ShahdFlix`.
2. Upload the contents of this folder (not the ZIP file itself) to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch **main** and folder **/(root)**, then Save.
6. Wait for GitHub Pages to publish the site. The URL will look like `https://YOUR-USERNAME.github.io/ShahdFlix/`.

## Important
This is a front-end demonstration. Login and registration forms perform browser-side validation only. They are not connected to a database, real user accounts, or payment services.
